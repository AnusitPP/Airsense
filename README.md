# 🌫 AirSense - แอปตรวจค่าภุ่น PM2.5 แบบเรียลไทม์

AirSense เป็นแอปพลิเคชัน Flutter สำหรับตรวจค่าภุ่น PM2.5 แบบเรียลไทม์ โดยใช้ OpenWeather API

## 🚀 ฟีเจอร์หลัก

- 🔎 ตรวจค่าภุ่น PM2.5 ตามพื้นที่เลือก
- 📌 ดึงข้อมูลพิกัดปัจจุบันโดยใช้ GPS
- 📢 ระบบแจ้งเตือนเมื่อค่าภุ่นเกินมาตรฐาน (ฟีเจอร์ในอนาคต)
- 🌍 รองรับการค้นหาพื้นที่และแสดงผลคุณภาพอากาศ

## 📺 เทคโนโลยที่ใช้

- **Flutter** 🐦 (Dart)
- **OpenWeather API** 🌍
- **Provider / Riverpod** (สำหรับการจัดการสถานะ)

## 🛠 การติดตั้งและรันโปรเจกต์

1️⃣ **Clone โปรเจกต์จาก GitHub**

```sh
git clone https://github.com/AnusitPP/Airsense.git  
```

2️⃣ **เข้าไปที่โฟลเดอร์โปรเจกต์**

```sh
cd Airsense  
```

3️⃣ **ติดตั้งแพ็กเกจที่จำเป็น**

```sh
flutter pub get  
```

4️⃣ **รันแอปบน Emulator หรือ Device จริง**

```sh
flutter run  
```
